# Asset provenance
Room art, all four broadcast illustrations, grain, rainy skyline and object detailing are original SVG authored for this study. `author-scene.py` deterministically produces the inline illustration; it does not copy reference models, artwork or code. Room and objects are illustrative, not a real-home photograph or project proof. No portrait used.
Final refinement: `author-scene.py` also authors the new pane reflections/droplet lenses, local reflected pools, ceramic mug/saucer volume, curved terracotta pot and leaf detail, turntable plinth/platter/tonearm/dust-cover depth and cabinet recess/walnut variation. These are original procedural vector contours and layered light cues, not borrowed Felix pixels or assets, photographs, physical simulation or a reconstruction of Victor’s home.
Reference privately inspected: https://www.landing.love/sites/felixrieseberg/ and researcher live capture of https://felixrieseberg.com/?ref=landing.love (group-a/11-felix-{desktop,mobile,reading}.png). Reference pixels do not ship.
Font: Archivo Black, Google Fonts upstream, SIL Open Font License; self-hosted `assets/archivo-black.ttf` and `assets/OFL.txt`. Body uses platform sans-serif; captions use platform monospace for broadcast control labels. No external runtime dependencies. Browser screenshots are evidence, not shipping assets.
