# Exact asset provenance
- All four gallery artworks: independently authored deterministic Three.js sculptures in gallery.js, createArt(canvas,index), indices 0–3. No image-generation service, stock imagery, borrowed Natalie artwork, or user portrait. Geometry: deformed sphere membranes, closed spline tube paths, spheres, torus knots. Materials: opaque MeshPhysicalMaterial pearl/emerald plus glass(color,thickness) dielectric transmission=1, metalness=0, roughness=.075, IOR=1.38, emerald thickness=.24 and violet=.18, attenuationDistance=2.8. Glass is assigned to six emerald petals (study 0), the inner violet spline (study 1), three violet petals (study 2), and the central emerald knot ribbon (study 3); other materials remain opaque. Environment: environment() CanvasTexture gradient and three white light strips; backdrop(index) independently draws curved bands to a 1024px CanvasTexture placed on a 9×9 scene plane at z=-2.5. No external HDR.
- Browser-generated PNG data URLs originate only from renderer.render(scene,camera) followed by canvas.toDataURL. These are in-memory renders, not shipped raster files. The single hidden transparent GIF initializes the closed dialog image; it is not gallery artwork.
- assets/three.module.js: upstream Three.js 0.169.0, https://cdn.jsdelivr.net/npm/three@0.169.0/build/three.module.js. MIT license in THREE-LICENSE.txt.
- assets/manrope.ttf: Google Fonts Manrope regular via https://fonts.gstatic.com/s/manrope/v20/xn7_YHE41ni1AdIRqAuZuw1Bx9mbZk79FO_F.ttf. SIL OFL text in Manrope-OFL.txt. Other weights are browser synthesis.

- All control icons: authored inline SVG paths in index.html, common viewBox 0 0 24 24 / 18px size / 1.4px rounded currentColor stroke in style.css. No icon fonts or Unicode substitutes.
- .impeccable/review/*.png: actual Chromium screenshot evidence created by verify.cjs against local HTTP, not gallery source assets. desktop-before-transmission.png and mobile-before-transmission.png retain the original pre-fix captures for same-size comparison. All six existing current screenshots were regenerated from the final runtime. No abandoned shipping artwork rasters exist: assets contains only the font, library, and their licenses.

## Exact regeneration procedure
From this study directory, serve `python -m http.server 8919 --bind 127.0.0.1` in a separate foreground terminal; then run `node verify.cjs`. The script uses existing Playwright at `/home/trex/vhmc/projects/devPilot/node_modules/playwright`, headless Chromium with `--no-sandbox --enable-unsafe-swiftshader`, desktop 1440×900 and mobile 390×844. Waits for galleryReady and document.fonts.ready, then writes viewport/full-page/detail PNGs to `.impeccable/review/` and checks to results.json. On each page load, gallery.js deterministically rebuilds each sculpture at 780×780 CSS pixels with pixel ratio capped at 1.5, ACESFilmicToneMapping exposure 1.25 and SRGB output, snapshots canvas.toDataURL, then releases the WebGL context. Stop the loopback server after verification. No runtime raster files are exported, copied, or manually retouched.
