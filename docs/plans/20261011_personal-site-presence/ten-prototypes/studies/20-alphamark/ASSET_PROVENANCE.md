# Asset provenance
All SVG plates are original programmatically authored vector illustrations for Field Editions, created locally in this study. No reference pixels, logos, client covers, photos, models or proprietary fonts were reused. intent.svg: printed multi-layer technical folio on an ink-blue drafting field. curiosity.svg: unbranded imagined circuit assembly, individually routed copper-like traces, sockets, solder pads and ribbed heat sink. judgment.svg: original typographic editorial folio. intent-mobile.svg: original separately composed portrait folio with resized typography and complete, unclipped printed message. These are representative illustrations, not actual projects/hardware photographs; visible captions disclose that status. SVG sources preserve the artwork directly; no shipping raster assets.
Manrope variable font: Google Fonts upstream https://github.com/google/fonts/tree/main/ofl/manrope ; downloaded font and verbatim SIL Open Font License shipped as assets/manrope.ttf and assets/manrope-OFL.txt. No Alphamark font reused. Icons: locally authored inline SVG arrow and menu strokes.
