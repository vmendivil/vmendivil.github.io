# 15 — Wideframe

Complete local Preymaker-inspired original personal image essay. Runtime is `index.html`, `style.css`, `app.js`, and `assets/` only. No live rendering library, remote runtime request, video autoplay or WebGL requirement.

## Run
From this folder: `python -m http.server 9115 --bind 127.0.0.1`. Visit http://127.0.0.1:9115/. Parent owns LAN assembly; do not copy private tools, documentation or evidence to the public runtime.

## Reproduce
- `node tools/render.cjs`: renders the four original modeled plates using the existing read-only Playwright dependency and loopback server. Render tools contain locally copied MIT Three.js.
- `node tools/verify.cjs`: six-viewport reading/layout/input/capture pass.
- `node tools/interaction.cjs`: all chapter links, touch return, close and native modal focus isolation.
- After re-rendering, embed the exact authoring provenance into each JPEG with Impeccable `embed-prompt <image> --prompt-file tools/plate-provenance.txt`.

Do not rerun the mechanical detector: this build ran it once and retained `detector-raw.json`.
