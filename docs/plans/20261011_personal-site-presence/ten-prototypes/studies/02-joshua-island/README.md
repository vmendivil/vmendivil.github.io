# Curiosity Archipelago — prototype 02

Self-contained original illustrated island experience for Victor Mendivil, inspired by the interaction grammar of the user-selected Joshua reference.

## Run locally
From this directory: `python -m http.server 8912 --bind 127.0.0.1`, then open `http://127.0.0.1:8912/`. Worker server is stopped after verification. Parent owns LAN hosting/launcher.

Shipping files: `index.html`, `style.css`, `world.js`, all `assets/`. All references are relative. No build, package installation, external runtime requests, form, storage or delivery. Three.js r170 and fonts are vendored with licenses.

## Explore
Choose an in-scene landmark or its bottom navigation item. The workshop covers professional practice; Pi harbour covers technical interests; the lookout covers personal introduction, availability and real LinkedIn contact. Whole map or Escape returns. Tab plus Enter/Space operates native buttons. Touch navigation works without dragging. Portrait selection exposes a closer camera above a scrollable story. Pause stops ambient effects; reduced-motion state snaps to destination. WebGL failure preserves the stories.
